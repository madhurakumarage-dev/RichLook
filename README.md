# Rich Look - Fashion E-Commerce App

A modern, production-ready fashion e-commerce mobile application built with Flutter.

## Overview

**Rich Look** provides a premium shopping experience with a clean, dynamic, and responsive UI. The app follows a clean architecture separating screens, models, and providers, and utilizes the `Provider` package for state management.

## Features

*   **Beautiful UI/UX:** Built with a custom design system, including tailored typography (Google Fonts) and a cohesive color palette.
*   **Product Discovery:** Browse products with category filtering and a responsive grid layout.
*   **Product Details:** View detailed product information, select sizes/colors, and add items to the cart.
*   **Cart Management:** Reactive cart state updates with seamless checkout flow.
*   **User Profile:** Manage user details and preferences in a clean profile interface.
*   **Smooth Animations:** Engaging micro-animations (like cart badges) for a polished feel.

## Tech Stack

*   **Framework:** Flutter
*   **State Management:** `provider`
*   **Fonts:** `google_fonts`

## Getting Started

To run this project locally:

1.  **Ensure Flutter is installed:** Follow the instructions on the [official Flutter website](https://docs.flutter.dev/get-started/install).
2.  **Clone the repository.**
3.  **Install dependencies:**
    ```bash
    flutter pub get
    ```
4.  **Run the app:**
    ```bash
    flutter run
    ```

## Firebase Setup

This app uses Firebase for authentication, Firestore, and storage. To configure Firebase for local development:

1.  **Create a Firebase project**
    * Go to the [Firebase Console](https://console.firebase.google.com/) and create a new project.

2.  **Add Android app**
    * Register your Android package name (for example `com.example.app`).
    * Download `google-services.json` and place it in `android/app/`.
    * Make sure the Android app config in `android/build.gradle.kts` and `android/app/build.gradle.kts` includes the Google services plugin.

3.  **Add iOS app** (if building for iOS)
    * Register your iOS bundle identifier.
    * Download `GoogleService-Info.plist` and add it to `ios/Runner/`.
    * Open `ios/Runner.xcworkspace`, then make sure the file is included in the Runner target.

4.  **Enable Firebase services**
    * In Firebase Console, enable **Authentication** and choose the sign-in methods you want (email/password is required by this app).
    * Enable **Firestore Database** and create a Cloud Firestore database in production or test mode.
    * Optionally enable **Firebase Storage** if you plan to use storage features.

5.  **Generate Firebase options**
    * This project includes `lib/firebase_options.dart` generated by the FlutterFire CLI.
    * If you need to regenerate it, install the FlutterFire CLI and run:
      ```bash
      dart pub global activate flutterfire_cli
      flutterfire configure
      ```
    * Confirm the generated `firebase_options.dart` is up to date for your Firebase project.

6.  **Install dependencies**
    ```bash
    flutter pub get
    ```

7.  **Run the app**
    ```bash
    flutter run
    ```

### Notes

* If your app uses Android signing or Google Play App Signing, add the correct SHA-1 / SHA-256 keys in the Firebase Console.
* If Firebase is not configured correctly, the app may fail during startup or when attempting authentication/firestore operations.
